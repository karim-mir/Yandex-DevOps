# YandexDevOps
Простое веб-приложение, которое развернуто на `Docker` контейнере

## Запуск 
- Необходимо собрать образ с помощью команды:
```
docker build -t my-web-app:latest fullpath
# fullpath - полный путь до директории test-project
```
- Запустить контейнер из образа:
```commandline
docker run -d -p 8080:80 --name my-web-app-container my-web-app:latest
```
- Проверить в браузере:

http://localhost:8080

# Очистка старых лог-файлов

Bash-скрипт для поиска и удаления старых лог-файлов (.log) в указанной директории.

## Описание

Скрипт `clean_old_logs.sh` выполняет поиск файлов с расширением `.log` в указанной директории, которые старше заданного количества дней, и предоставляет возможность их удаления после подтверждения пользователем.

### Использование
- Скачайте скрипт
```
git clone <https://github.com/karim-mir/Yandex-DevOps>
```
- Команда для запуска скрипта:
```
./clean_old_logs.sh <путь_к_директории> <количество_дней>
```

### Примеры:
- Показать справку (неправильное количество аргументов):

```
./clean_old_logs.sh
```
- Найти файлы старше 30 дней в директории /YandexDevOps/test-project/test-logs:

```
./clean_old_logs.sh /YandexDevOps/test-project/test-logs 30
```
- Найти все .log файлы (старше 0 дней):

```
./clean_old_logs.sh ./logs 0
```
- Найти файлы старше 7 дней в текущей директории:

```
./clean_old_logs.sh . 7
```
